How it works

FAQ

Questions, answered

A notes app for your Mac that feels like a modern editor and behaves like a folder of files. You write rich documents with headings, checklists, tables and equations, and each one is saved as a Markdown file on your Mac.

In the Drawer folder in your Documents, one Markdown file per note, in real folders that match yours in Drawer. Nothing is uploaded anywhere, and there is no account.

Yes. They are plain Markdown, so any text editor can open them. If you stop using Drawer, your notes stay exactly where they are.

Fully. Writing, search, templates, locked notes and PDF export all work without a connection. Only writing help from Claude needs the internet.

A locked note's writing is encrypted on disk with AES-256, using a key made from your password. Drawer never stores the password. It opens with Touch ID or the password, and locks again when you close it or your Mac sleeps. Titles and pictures aren't encrypted, only the writing.

No. Writing help from Claude is off until you turn it on. When you ask, Drawer sends only the text you selected and your request, never anything else, and never a locked note.

If you have a Claude Pro or Max plan, Drawer can use it through Claude Code on your Mac, so it counts toward your plan's usage with no extra bill. You can also use your own Anthropic API key and pay as you go.

If they're in Markdown, yes: drop the files into the Drawer folder in Documents and they appear the next time you open Drawer. There are no importers for other apps yet.
